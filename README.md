# 循迹 - 运动健康管理应用

> 用AI追踪每一次奔跑，让数据成为你进步的阶梯。

## 🌟 项目简介

循迹是一款专为跑者设计的运动健康管理Web应用。通过上传运动手表跑步数据截图，AI会智能识别分析，提供专业的点评和指导意见，帮助你科学训练、长期追踪成长轨迹。

## ✨ 核心功能

### 📊 智能分析
- 上传运动手表截图，自动识别跑步数据
- AI深度点评每次跑步效果
- 个性化训练建议和恢复指导

### 🌳 生命树系统
- 可视化成长轨迹
- 等级进阶系统（幼苗期 → 绚烂期 → 极光期...）
- 勋章成就系统
- 成长日志记录

### 📈 数据追踪
- 长期趋势分析
- 心率区间分布图
- 能力雷达图
- 里程碑记录

### 🔥 游戏化体验
- 连续打卡挑战
- 经验值积累
- 等级提升奖励

## 📱 页面导航

1. **首页** - 恢复度仪表盘、AI洞察、活动列表
2. **分析** - 长期趋势、健康预测、能力雷达
3. **生命树** - 成长轨迹可视化、等级系统
4. **痕迹** - 跑步历史记录时间线
5. **我的** - 个人设置、数据管理

## 🎨 设计特色

- **深色玻璃态UI** - 护眼且现代感十足
- **流畅动画** - Framer Motion驱动的丝滑交互
- **移动优先** - 完美适配手机屏幕
- **响应式设计** - 支持各种设备尺寸

## 🛠️ 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式方案**: Tailwind CSS
- **动画库**: Framer Motion
- **图表库**: ECharts
- **状态管理**: Zustand
- **字体**: Hanken Grotesk, Inter, JetBrains Mono
